# AI Memory Architecture (АРИАРИХИВАРИУС)

## Проблема
Современные ИИ-ассистенты "забывают" начало разговора после 10-15 сообщений. Это ломает возможность вести сложные диалоги.

## Решение
Многоагентная система специализированных модулей:
Пользователь 
    → РОТ (общение с человеком)
    → ШЕРИФ (координатор)
    → [СЫЩИК + ЭКСПЕРТ + СУДЬЯ] (обработка данных)
    → АРХИВАРИУС (формирование ответа)
    → РОТ → Ответ

Каждый модуль выполняет одну задачу идеально. Система сохраняет ключевые моменты диалога, избегая переполнения памяти.

## Для кого это нужно
- Разработчикам чат-ботов
- Компаниям, использующим ИИ в поддержке клиентов
- Всем, кто хочет качественных долгих диалогов с ИИ
